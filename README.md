# Liquid Habits panel for Excel

A liquid-glass side panel for **Habit Tracker.xlsm**: tick off today's habits with a glass look
and a pointer-following lens. Ticks are written straight into the `tblTracker` table on the Tracker sheet.

- `taskpane.html` is the panel (hosted with GitHub Pages).
- `manifest.xml` is what you add to Excel (Add-ins > My Add-ins > Upload My Add-in).
- `full.html` is the whole tracker, shown as a box on its own worksheet (`manifest-full.xml`).
